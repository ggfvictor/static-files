# Scan Setup v0.2 | 扫描到个人电脑配置助手

**内部试运行版（非生产签名版本）** · Windows 10/11、统信 UOS 桌面版、HarmonyOS PC

目标：在员工真实桌面创建 `scan` 文件夹，以独立账号 `scan` 进行 SMB 共享，生成每台电脑独立的 20 位随机密码，确认办公网 IPv4，并输出统一的打印机地址簿信息。支持时自动复制到剪贴板。工具不会自动联网发送凭据，也不会配置打印机。

## v0.2 更新：统一控制台配色

- 青色：标题、信息与操作说明；黄色：待输入、手动操作与警告；绿色：已完成的操作；红色：错误；紫色：需提交给 IT 的配置信息。
- 最终报告由“复制开始”和“复制结束”两条紫色分隔线标识。自动复制成功时，用户直接粘贴即可；自动复制失败时，手动复制两条分隔线之间的全部内容（不含分隔线）。
- 剪贴板始终使用原始纯文本报告，不含 ANSI 颜色或分隔线。Shell 在非交互输出、TERM=dumb 或设置 NO_COLOR 时退回纯文本；Windows 使用 PowerShell 原生颜色，设置 NO_COLOR 可关闭新增的配色。
- 本版仅调整显示和操作提示；SMB 配置、账号、随机密码、权限和防火墙逻辑保持原样。为兼容原版检测，现有内部防火墙规则名称及 Samba 配置标记仍保留 v0.1。
- v0.2 尚未在三个平台的真实设备上验证；鸿蒙终端实际颜色及剪贴板支持仍需实测。

## 1. 文件与运行方法

先完整解压压缩包，不要直接在压缩包内运行。

| 系统 | 文件 | 运行方法 |
|---|---|---|
| Windows 10/11 | `Start-Windows.cmd`、`setup-windows.ps1` | 员工在自己的桌面会话双击 CMD；按 UAC 提示授权。两个文件须在同一目录。 |
| UOS | `setup-uos.sh` | 员工在脚本所在目录打开终端，执行 `bash setup-uos.sh`，按提示授权 sudo。不要用 sudo 启动整个脚本。 |
| HarmonyOS PC | `setup-harmonyos.sh` | 在文件管理中进入脚本所在目录并打开终端，执行 `sh setup-harmonyos.sh`；按照终端指引确认桌面及手动完成 SMB 设置。 |

Windows 请使用 64 位 Windows PowerShell 5.1。启动器不绕过 PowerShell 执行策略。如果企业策略、文件下载标记或应用控制拦截脚本，由 IT 审核、签名或按企业流程解除拦截；不要关闭安全策略。

UOS 需要已批准的 sudo 权限，适用于可使用 Debian 风格 APT、Samba 与 systemd/smbd 的桌面版本。若缺少 Samba、smbclient 或剪贴板工具，会提示从现有软件源安装，不自动修改软件源或开启开发者模式。若终端安全策略禁止安装，由 IT 处理。UOS 原生文件管理器的共享服务可能与标准 Samba 不同，若发现已有配置请先人工核查。

鸿蒙电脑需 HarmonyOS 6.0.0.115 或以上。由于尚未发现受支持的原生 Shell 接口可管理鸿蒙 SMB 服务及网络用户，脚本不会假设 Linux Samba 命令在鸿蒙存在，也不会尝试提权。桌面路径候选未经真机验证：员工须在图形界面确认；若终端无法访问桌面，直接在文件管理中创建 `scan`。如果需要，可指定已确认的真实桌面目录：`sh setup-harmonyos.sh "/实际桌面路径"`。原生剪贴板 Shell 接口亦未确认；仅在可用剪贴板工具存在时尝试自动复制，否则用终端手动复制。

## 2. Windows / UOS 配置流程

1. 连接办公网络，选择打印机可访问的 IPv4。不要选择 VPN、虚拟网卡、访客 Wi-Fi 或错误的网口。
2. 输入打印机 IPv4（多个用英文逗号隔开）。若暂时不知道，可回车使用本地子网范围；生产建议由 IT 提供具体的打印机 IP，不要开放到整个网络。
3. 输入员工姓名（用于打印机通讯录显示），确认配置。
4. 等待脚本输出配置，复制内容并通过经批准的安全渠道提交 IT。

Windows 创建普通本地用户，添加 `scan` 目录 NTFS 修改权限，创建同名 SMB 共享并允许内置管理员管理共享；启动 Windows SMB Server，新增仅 Private/Domain 网络、所选接口和指定来源范围的 TCP 445 入站规则。不会关闭防火墙、修改现有规则、改变网络类别或启用 SMB1。Windows 本地账号仍受本机登录策略控制，IT 应按企业策略限制该专用账号交互式/RDP 登录；本版不修改全局用户权限分配。

UOS 创建无登录 Shell、无家目录的 Unix 系统账户，并为其设置 Samba 密码；共享只允许该 SMB 账户、指定来源范围，禁用 guest，按员工身份读写目标目录，以便扫描文件能由员工管理。脚本先备份 `/etc/samba/smb.conf`，追加 `scan` 段，经 `testparm` 验证后启用/加载 `smbd`，并通过 `smbclient` 做本机 SMB2/3 认证、写入、删除测试；若 UFW 已启用，添加来源受限的 445/tcp 规则。若存在其他防火墙、Samba 全局访问限制或非独立 Samba 角色，需 IT 检查；工具不会关闭或覆盖现有策略。

本版仅支持首次配置。Windows/UOS 如果发现已有 `scan` 账户或共享、已有本工具防火墙规则（Windows）、已有文件的 `scan` 目录等冲突，停止而非覆盖或重置密码；如果配置中途失败，会尽力撤销本次新建的账户/共享，不会删除员工文件。可能保留空目录、已安装软件、启动的服务、Samba 备份等。需 IT 核查后再运行。不要盲目删除原有账号或配置。

## 3. HarmonyOS 手动确认步骤

1. 确认桌面 `scan` 文件夹存在且没有非扫描资料。
2. 文件管理 > 更多 > 设置 > 网络共享；首次使用按提示安装网络邻居服务，点击保存并关闭。
3. 网络用户管理 > 添加用户，输入脚本显示的 `scan` 和随机密码。若已有同名用户请 IT 核查，不要直接重置。
4. 右键桌面 `scan` > 授予访问权限 > 特定用户；仅添加 `scan` 用户并授予读取/写入权限。检查共享名为 `scan`。
5. 完成后回终端输入 `DONE`，输出并尝试复制配置。

注意：华为官方扫描回传文档要求 SMB1/CIFS 兼容支持。工具默认不启用 SMB1。由 IT 首先验证打印机是否可通过 SMB2/3 完成扫描；如鸿蒙/打印机组合必须使用 SMB1，须单独批准、限制网络来源并评估风险，或改用受控的集中扫描服务器。端口 445 为优先测试值，并非所有打印机/鸿蒙组合都已验证。

## 5. IT 管理员录入与验收

在对应打印机的 Web 管理后台新建 SMB 通讯录联系人：

- 联系人显示名：员工姓名；服务器地址：员工电脑办公网 IPv4；端口：优先 TCP 445；共享名称：scan；共享内子目录：留空；用户名与密码：报告中的独立 SMB 凭据；禁用匿名登录。
- 施乐/富士：服务器 IP 与共享名分别填写，若有子目录字段留空。
- 理光：文件夹路径通常使用 `\\IP\scan`，Windows 登录名优先尝试 `计算机名\scan`；如界面有域字段，按本机名/用户名字段填写。UOS、鸿蒙一般使用 `scan`。
- 奔图：按型号使用 SMB 服务器、SMB 子目录/共享路径字段；华为官方奔图示例使用 `/scan`，不是完整 UNC；端口需按实际固件、服务能力核实。优先测试 TCP 445，勿盲目开启 139/SMB1。
- 其他品牌：根据具体型号/固件调整。以上为通用字段映射，不代表已测试全部打印机。

验收步骤：IT 管理终端先确认网络路由、VLAN ACL、TCP 445 连通；可用 `Test-NetConnection 192.168.10.105 -Port 445`（Windows）或 `smbclient //192.168.10.105/scan -U scan -m SMB3`（Linux，交互输入密码）测试。但如果脚本已限制为仅打印机 IP，IT 管理电脑可能被有意拒绝，不应为测试随意放宽范围。最终必须从实际打印机执行扫描，在员工桌面打开 PDF 并确认读写正常；重启/锁屏后再次测试，并验证其他网络来源不能访问。

## 6. 安全与部署建议

- 建议 IT 预先固定打印机地址，并为电脑配置 DHCP 保留地址，或采用经验证的稳定主机名，防止 IP 变化后地址簿失效。笔记本休眠、关机、断网时无法实时接收扫描。
- 所有电脑使用同一用户名 `scan`，但每台电脑独立生成密码，禁止使用员工登录密码、统一弱密码或匿名共享。默认随机密码 20 个 ASCII 字符（64 位随机部分，带大小写、数字与符号），如设备固件限制密码长度由 IT 评估后调整。
- 密码只在终端、剪贴板及打印机配置中使用；脚本不创建持久明文配置文件。UOS 本机测试会使用临时 root 专属凭据文件，退出时删除。剪贴板/终端可能保留明文历史，提交给 IT 后及时清除；不要发到公共群、普通工单或公开日志，不要共享密码截图。打印机地址簿也应限制导出/读取权限。
- 不关闭任何防火墙，不自动启用 SMB1，不修改系统网络类别，不更改现有密码。来源限制仅约束本工具新增规则/共享；已有更宽松的防火墙规则或设备管理策略可能影响有效边界，IT 应核验实际策略。
- 生产部署前，各选一台 Windows、UOS 和 HarmonyOS 实机，以及各品牌打印机，执行端到端测试。若标准用户无管理权限，建议由 IT 统一签名和部署，不要把管理员口令发给员工。
